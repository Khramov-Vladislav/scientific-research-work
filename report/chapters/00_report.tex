\section*{РЕФЕРАТ}

Отчёт о научно-исследовательской работе изложен на \textbf{36}~страницах,
содержит \textbf{6}~иллюстраций, \textbf{7}~таблиц,
\textbf{14}~использованных источников, \textbf{1}~приложение.

Ключевые слова: распределённые вычислительные системы, диспетчер
заданий, SLURM, имитационное моделирование, нормальное распределение,
логнормальное распределение, анализ датасета, виртуальный кластер, SSH.

Объектом исследования являются методы диспетчеризации и планирования
вычислительных ресурсов в распределённых кластерных системах под
управлением системы управления заданиями SLURM на базе операционной
системы Linux в среде виртуализации.

Целью работы является разработка программного имитатора
пользовательских заявок на основе статистического анализа исторических
данных вычислительного кластера (вариант:~UID~50430,
JobName~\texttt{run\_bwa.sh}) и исследование динамики прохождения
сформированных заявок через реальный диспетчер SLURM с применением
механизмов масштабирования времени.

Методология работы включала развёртывание виртуального вычислительного
кластера из пяти узлов средствами Oracle VM VirtualBox, статистический
анализ выборки учётных данных acct\_0921-0923 с вычислением границ
диапазона фактического времени выполнения и параметров логарифма ошибки
оценки времени выполнения, формируемой пользователем, а также натурный эксперимент
по постановке сгенерированных заявок в очередь диспетчера.

Результатом разработки стал комплекс программно-управляемых скриптов
на языках bash и Python, обеспечивающий фильтрацию исходного датасета,
генерацию случайного потока заявок с усечением границ диапазона и их
автоматическую отправку в пакетный диспетчер SLURM. Средствами SLURM
собрана и проанализирована итоговая статистика соотношения
«план\,---\,факт» для верификации использованной статистической модели.

Результаты работы могут быть использованы в учебном процессе при
изучении технологий организации высокопроизводительных вычислений,
администрирования распределённых систем под управлением SLURM.
